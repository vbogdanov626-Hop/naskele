# Инструкция по доступу к админ-панели

## Проблема
На хостинге админ-панель может не работать из-за ограничений localStorage или других причин.

## Решения

### 1. Прямой доступ через URL
Добавьте `?admin=1` к URL главной страницы:
```
https://yourdomain.com/index.html?admin=1
```

### 2. Прямой доступ к админ-панели
```
https://yourdomain.com/admin.html?admin=1
```

### 3. Тестовая страница
Используйте тестовую страницу для проверки:
```
https://yourdomain.com/admin-test.html
```

### 4. Ручной вход
Если localStorage не работает, используйте параметр `?admin=1` для обхода авторизации.

## Пароль админ-панели
Пароль: `admin123`

## Проверка работоспособности
1. Откройте `admin-test.html`
2. Проверьте доступность localStorage
3. Если localStorage недоступен, используйте URL с `?admin=1`
4. Введите пароль `admin123` для входа
